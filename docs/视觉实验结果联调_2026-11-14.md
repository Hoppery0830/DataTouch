## 接线与流程

- 补光控制改用 **F4 PD14**：高电平开灯、低电平关灯；初始化先写低电平再切换为推挽输出。连接灯驱动模块的控制输入，并共地。PD14 预留给补光控制。
- K230 GPIO11/TX → F4 PA10/RX；K230 GPIO12/RX ← F4 PA9/TX；共地，115200、8N1、3.3 V TTL。
- 默认 `TOUCH_USART1_K230=1`。PC 文本模式可以编译，但不允许视觉实验 START。
- 选择模式 → ARM 准备三轴 → START → 三轴停稳检查至少 200 ms，且取得 START 之后的位置/状态反馈 → 开灯等待 2 秒 → 请求一次采图 → 收到采图完成后关灯 → 放行运动。
- 采图期间继续检查三轴状态和位置变化；超时、STOP、RESET 或心跳失效会取消采图并请求关灯。这里确认的是 GPIO 输出已关，不是灯具光学反馈。
- K230 在独立图像上计算 U_curve；计算和运动可以重叠。结果未交给 ESP32 持久化之前，新 START 返回未就绪，保留上一轮结果。计算失败且没有结果时，需要 STOP/RESET 取消该轮，再重新 ARM。

## 一次实验一条结果



实验令牌为 START 命令序号 uint32 + 本轮开灯时 F4 毫秒计数 uint32。串口采用小端；数据库字符串按两个 uint32 各八位十六进制拼接。它不是 UTC 时间或跨设备 UUID，数据库还按 deviceId 隔离。相同令牌出现不同值会拒绝，不覆盖旧记录。

| 链路 | 帧类型/内容 | 确认和重试 |
| --- | --- | --- |
| F4 → K230 | 0x30，令牌 8 字节 | 发出成功后不重发采图请求 |
| K230 → F4 | 0x31

，令牌 + 采图状态 | 重发通知，不重复拍照；最多等待 3 秒放行 |
| F4 → K230 | 0x32，令牌 + 关灯放行状态 | 重复通知只回放结果 |
| K230 → F4 | 0x33，令牌 + float32 U_curve | 最多 5 次，每次等待确认 500 ms |
| F4 → K230 | 0x34，令牌 + 接收状态 | 0 成功、1 拒绝、2 忙；成功仅表示 F4 已接收 |
| F4 → ESP32 | 0x22，令牌 + float32 U_curve | 最多 10 次发送尝试，间隔至少 500 ms |
| ESP32 → F4 | 0x23，令牌 + 状态 | 写入 NVS 成功才返回成功 |
| ESP32 → 云函数 | action=visualResult | 云端保存或确认已有相同记录后返回匹配 visualAck |

K230 链路使用原协议累加校验；ESP32 链路使用远程协议 CRC8，不能互换。U_curve 必须有限、非负且不超过 1e6；算法标识为 `gunay-full-curve-v1`。

ESP32 提供 8 个持久化槽，未上传的记录不会被覆盖；满队列不确认新结果。每次启动每条记录最多尝试上传 5 次，失败退避，耗尽仍保留 NVS；重启后重新尝试。F4 转发耗尽保留待发送结果，显式 STOP/RESET 允许新一轮有限转发。云端确认丢失时重试只返回同一条记录，不重复插入。

F4 接收缓存仅在 RAM：ESP32 持久化确认之前 F4 掉电仍可能丢失结果。K230 同时把令牌及结果追加到 `/sdcard/data_touch_results/u_curve.txt.tokens`（写入失败会记录日志），该文件用于追溯，不自动补传。当前不承诺任意掉电时刻都自动恢复。

## 云端与小程序部署

1. 在当前云环境创建 `visual_results` 集合，配置 `deviceId` 升序、`receivedAt` 降序的组合索引。客户端通过云函数访问，不开放直接写入。
2. 部署主工程 `miniprogram/cloudfunctions/deviceCommand` 与 `sendCommand`，包括新增 `visual.js`、`telemetry.js`。沿用现有设备鉴权配置。
3. 若启用触觉遥测页，还需要现有遥测链路使用的集合与索引，见云函数 `telemetry.js`。
4. 在微信开发者工具导入主工程 `miniprogram` 并重新编译。远程控制页“视觉实验结果”入口按设备查看数据库记录，支持下拉刷新、分页；显示 U_curve、实验令牌、算法和云端接收时间。
5. 更新 F4、ESP32 固件，并使用 `K230/upload_k230_final_deploy.ps1` 更新 K230 Python 程序。K230 仍依赖现有包含 gunay_native 的定制固件。

数据库使用设备号与令牌的 SHA256 派生 `_id` 做不可变插入。只有云端保存完成的记录才出现在结果页；不再把旧 U_curve 作为持续触觉采样反复上传。页面的“已保存”是数据库状态，不代表动作一定成功完成。
