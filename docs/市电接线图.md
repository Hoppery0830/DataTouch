# 市电接线图 — AC 三合一座 → 明纬 LRS 端子排

> 目的：把机壳上的 **三合一 AC 输入座（IEC C14 品字座+开关+保险丝盒，面板/机壳安装）** 背面焊片，用 **0.75mm² 阻燃多股铜线** 接到 **明纬 LRS 的 L / N / FG 螺钉端子排**。

## 接线图
```
 [三合一 AC 座 背面(机壳装)]                    [明纬 LRS 端子排]
 ┌──────────────────────────┐               ┌──────────────────┐
 │  IEC C14 品字公座          │               │  L    N    FG    │
 │  ┌────┐   ┌───────────┐   │               │  (螺钉端子排)     │
 │  │开关│   │ 保险丝盒   │   │               │                  │
 │  │(L) │──▶│(L 进→L 出)│   │               │                  │
 │  └────┘   └───────────┘   │               │                  │
 │                           │               │                  │
 │  L_out ──[0.75mm² 棕/红]──► L  (火线)     │                  │
 │  N     ──[0.75mm² 蓝/黑]──► N  (零线)     │                  │
 │  E     ──[0.75mm² 黄绿]──► FG (外壳地 ⏚)  │                  │
 └──────────────────────────┘               └──────────────────┘
         ▲ 焊片端: 剥线~5mm 上锡, 焊到焊片, 套热缩管
         ▲ PSU端:  剥线, 压冷压端子, 拧进螺钉端子排, 别露铜
```

## 接线说明（三根线）
| 线 | 颜色 | 从(AC座) | 到(PSU) | 作用 |
|---|---|---|---|---|
| 火线 L | 棕/红 | 焊片 L_out（经开关→保险丝后那端）| 螺钉 **L** | 被开关+保险丝控制过的火线 |
| 零线 N | 蓝/黑 | 焊片 N | 螺钉 **N** | 零线 |
| 地线 E | 黄绿 | 焊片 E | 螺钉 **FG(⏚)** | 保护地，必须接 |

> 开关和保险丝已在 AC 座内部串在 **L(火线)** 通路上；所以你从背面接出的 **L_out 才是"受控+已过保险丝"的火线**。

## 两端处理
- **AC 座焊片端**：剥线约 5mm → 上锡 → **焊到焊片** → **套热缩管**绝缘（一根一根来）。
- **明纬端子排端**：剥线 → 压一个**冷压（U型/圆环）端子**（或直接插入）→ **拧紧螺钉**，别露铜丝。

## 线材要求
- **0.75mm² 多股铜线**，PVC/阻燃，**耐压 ≥300V**（UL1015 / RV 线 / VDE 认证线）。
- L/N 不同颜色，E 用**黄绿**；地线尽量**短**、同规格或略粗。
- 走线**短、贴近壳固定**（扎带），**避开锐边、发热件、电机功率线**。
- 焊点/端子全部绝缘；**市电操作务必断电**。

## 安全
- 断电操作；L/N/FG 别接反（用万用表先测）。
- E(黄绿) **必须**接 PSU 的 FG；2 芯无地线不可用。
- 用 **IEC C13 三芯带地电源线** 插进这个 C14 座（墙插那头带 PE）。
