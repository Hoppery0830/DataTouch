# 织物触觉舒适度检测系统 — 电源分配方案

> 220V 市电 → 明纬 LRS-100-12(12V/8.5A) → 12V轨(电机) + 12V→5V Buck(逻辑)

## 一、总示意
```
220V AC (L/N)
   │
   ├─[保险丝 F1: 3~5A 慢断]──(串在火线 L)
   │
   └─► LRS-100-12 开关电源
       输入端子:  L(火线)  N(零线)  FG(外壳/安全地, ⏚)
       输出端子:  +V=12V   −V=GND
          │
          ├──────────────────────────────► 12V 轨 （电机电源）
          │                                 ├── Z 电机驱动：+V / −V
          │                                 ├── X 电机驱动：+V / −V
          │                                 └── Y 电机驱动：+V / −V
          │                                 （12V 轨近电机处加大电解电容 ~1000µF 缓冲尖峰）
          │
          └─► 12V→5V Buck 降压模块（如 LM2596 / MP1584，12V输入→5V输出，额定 ≥2A）
                 │
                 └─► 5V 轨 （逻辑电源）
                        ├── STM32F407 板（5V 输入 / VIN）
                        ├── ESP32-S3（5V 输入 / VIN）
                        ├── 六维力传感器（若 5V 供电；若 12V 则改接 12V 轨）
                        ├── ADXL335（5V 或 3.3V；3.3V 需加小 LDO/稳压）
                        └── 有源蜂鸣器 TMB12A05（5V，经三极管/MOSFET 由 GPIO 开关）
```
**所有 GND 相通（共地）**：12V −V、5V Buck 的输入/输出 GND、电机驱动 −V、STM32/ESP32/传感器/ADXL/蜂鸣器 GND 全部接同一公共地。

## 二、LRS-100-12 端子确认（明纬 LRS 系列）
| 端子 | 符号 | 接法 |
|---|---|---|
| 输入 | **L**（火线）| 接市电 220V L（串保险丝）|
| 输入 | **N**（零线）| 接市电 220V N |
| 输入 | **FG/⏚**（外壳地）| 接机壳/安全地，防漏电/EMI |
| 输出 | **+V** | 接 12V 轨 / Buck 输入 + |
| 输出 | **−V** | 接公共地 GND（可多个螺丝，都同一网络）|

> 有的 LRS 输出端有多个 −V / +V 螺丝，都是同一网络，接哪里都行；注意别接反（+V 是 12V，不是 −）。

## 三、关键注意
1. **保险丝**：市电输入**火线 L 串一个 3~5A 慢断保险丝**。
2. **12V 轨缓冲电容**：电机电流是脉冲式，**在 12V 轨（近电机驱动处）加约 1000µF 电解**，并用 0.1µF 陶瓷就近退耦每台驱动。
3. **5V Buck 选型**：逻辑总电流约 **0.8~1.2A**（STM32 ~0.3A、ESP32 ~0.4A、力传感器 ~0.2A、ADXL/蜂鸣器/LED 小量）。**推荐 5V≥2A 的 Buck**（LM2596 或更高效模块），留足余量。
4. **力传感器供电电压**：确认它是 **5V 还是 12V/24V**——5V 接 5V 轨，12V 接 12V 轨（很多工业六维力是 12/24V 供电）。**别接错电压。**
5. **共地/接地噪声**：电机大电流会在地线上产生噪声，力传感器对地噪声敏感。建议 **星形接地**（电机驱动的地、逻辑地、传感器地分别走线，在一点汇接），并让**传感器信号线远离电机功率线**。
6. **安全**：220V 侧注意绝缘/机壳接地；LRS 自带过压/过流/短路保护。

## 四、分模块供电速查
| 模块 | 电压 | 来源 |
|---|---|---|
| 3× 闭环步进电机驱动 | 12V | 12V 轨（LRS 输出）|
| 六维力传感器 | 5V 或 12V（按手册）| 5V 轨 或 12V 轨 |
| STM32F407 | 5V | 5V 轨 |
| ESP32-S3 | 5V | 5V 轨 |
| ADXL335 | 5V 或 3.3V | 5V 轨（3.3V 需稳压）|
| TMB12A05 蜂鸣器 | 5V（经三极管开关）| 5V 轨 |
| 指示灯 LED | 3.3V/5V（经限流电阻）| 逻辑电源 |
