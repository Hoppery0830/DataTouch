# 明纬 LRS-100-12 接入 220V 市电 — 采购清单与接线

> 场景：把 **明纬 LRS-100-12（12V/8.5A）** 的 **L/N/FG 输入端子** 接上 220V 市电。
> ⚠️ 市电是致命电压，**务必断电操作**、做好绝缘与保护接地。

---

## 一、采购清单（2 种方式，二选一）

### 方式 A：样机 / 散件（插头直接进 PSU）
| 物料 | 规格建议 | 数量 | 说明 |
|---|---|---|---|
| **3 芯带地电源线** | 国标**三脚插头**，3 芯，**0.75mm²**，带地(PE)，长按需(1.5~3m) | 1 | 一端插头，一端剥线接 PSU |
| **保险丝 + 保险丝座** | 5×20mm 陶瓷慢断 **3.15A(或5A)** + 带线保险丝座(串联在火线L) | 1 | 保护市电端 |
| **船型开关** | 250V 10A 船型开关（或"开关+保险丝座"一体件）| 1 | 方便开关，串在火线 L |

> 线径 0.75mm² 稳；220V、~1A 电流很小，0.5mm² 也可但 0.75 更保险。

## 二、接线步骤（每步确认断电）
1. **断市电**，所有线披皮，用**压线端子/冷压端子**或直接拧入 PSU 端子排，拧紧、不留铜丝。
2. **火线 L**：`插头/开关 → 保险丝 → PSU 的 L`。
3. **零线 N**：`插头 → PSU 的 N`。
4. **地线 PE（黄绿）**：`插头/插座 → PSU 的 FG(外壳地 ⏚)` —— **必须接**。
5. 检查接线无误、端子绝缘良好，再通电。

### 接线示意
```
方式A:
插头L(棕) ─[开关]─[保险丝3.15A]─► PSU L
插头N(蓝) ─────────────────────► PSU N
插头PE(黄绿) ──────────────────► PSU FG(⏚)

方式B:
IEC插座: L ─[开关]─[保险丝]─► PSU L ； N ─► PSU N ； PE ─► PSU FG
```

---

## 三、安全注意
- **断电操作**；接线时别碰市电端子。
- **保护地 PE 一定接 FG**：金属壳有 Y 电容漏电流，不接地会有**麻电感**，故障时可能带电 → 必须 PE 接地。
- **线别露铜**、端子要绝缘、机壳要接地。
- 输出侧（+V/-V）接 12V 轨 + 12V→5V，**别接市电**。
- 使用前用万用表确认 L/N/PE 对应关系，避免接反（有些插头 L/N 颜色非标准，以万用表测为准）。
