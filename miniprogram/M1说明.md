## 2. `experiments` 集合字段说明（M1 实际写入的字段）

字段名严格沿用 `src/protocol.h` 的 `MetricsFrame` / `FRAME_SCORE` 命名。

| 字段 | 类型 | 必填 | 含义 / 取值 |
|---|---|---|---|
| `_id` | string | 自动 | 云数据库主键 |
| `deviceId` | string | ✅ | 设备唯一 ID（ESP32 MAC 派生），如 `YD32S3-3C6108A1` |
| `fabricName` | string | ✅ | 布料名（冗余，便于列表直接显示） |
| `operator` | string | — | 操作员（M1 用字符串；绑定体系落地后可回填 `operatorOpenid`），缺省 `""` |
| `softness` | number | ✅ | 柔软度，**STM32 归一化后的 [0,1]**，越大越软 |
| `smoothness` | number | ✅ | 顺滑度，[0,1]，越大越顺滑 |
| `roughness` | number | ✅ | 细腻度/粗糙度，[0,1]，**越小越细腻**（列表/详情展示「细腻度」时取反为 `100 - x`） |
| `rebound` | number | ✅ | 回弹贴合度，[0,1]，越大越好 |
| `composite` | number | ✅ | **综合评分 0-100**（权威值来自 STM32 `FRAME_SCORE`），保留 2 位小数 |
| `metricsNormalized` | boolean | ✅ | 四维是否已归一化到 [0,1]；权威链路恒为 `true` |
| `weights` | object | ✅ | 本次权重快照 `{softness:0.30, smoothness:0.25, roughness:0.20, rebound:0.25}`，便于复现 |
| `curveRef` | string | — | 抽稀曲线引用（云存储 fileID），M1 可为空字符串 |
| `dedupId` | string | ✅ | **幂等键**；缺失时云函数按 `deviceId-startedAt-composite` 生成 |
| `startedAt` | Date | ✅ | 实验开始时间（设备侧）；缺失时退化为入库时刻（对应 §5.6 退化策略） |
| `createdAt` | Date | ✅ | **服务端入库时间**（`new Date()`），列表排序依据 |
| `source` | string | ✅ | 数据来源，M1 固定 `"device"` |

> 与 §3.1 完整表的差异（**M1 有意裁剪，非缺失**）：
> `openid` / `deviceName` / `fabricId` / `fabricCode` / `mode` / `state` / `metricsFlags` /
> `calibrationVersion` / `endedAt` / `t0_relative_duration_s` / `sampleCount` /
> `curveFileId` / `resultFileId` / `notes` / `operatorOpenid` / `syncState` / `schemaVersion`
> 这些留到 M2/M4（设备绑定、标定、曲线）再补，不影响 M1 的读写闭环。

### 建议索引

| 索引 | 字段 | 类型 | 用途 |
|---|---|---|---|
| 幂等 | `dedupId` | **唯一**（升序） | 保证重复上报不产生重复记录 |
| 列表排序 | `createdAt` | 降序 | 列表「按 createdAt 倒序 + 分页」的性能 |

> 在 云开发控制台 → 数据库 → `experiments` → **索引管理** 里添加。
> ⚠️ 若已有重复 `dedupId` 数据，唯一索引会创建失败；M1 数据量小，先清空再建即可。

## 3. 你必须手动做的步骤（控制台操作）

### 步骤 1：确认云环境

1. 打开「微信开发者工具」→ 打开工程 `F:\微信web开发者工具\miniprogram`
2. 顶部工具栏点 **云开发** → 确认环境列表中存在 **`cloud1-d5gncnkxj2606d114`**
3. 若环境 ID 与上面不同：请把 `miniprogram/app.js` 里的 `env` 改成你自己的环境 ID（**这是唯一需要改的地方**）

### 步骤 2：新建集合 `experiments`

1. 云开发控制台 → **数据库** → **+ 新建集合** → 集合名输入 **`experiments`** → 确定
2. 选中 `experiments` → **权限设置** → 选择 **「所有用户可读，仅创建者可读写」** 或 **「所有用户可读，仅管理端可写」**
   - M1 联调推荐：**「所有用户可读，仅管理端可写」**（列表页靠客户端直读，写只走云函数）
   - ⚠️ 注意：云函数写入的文档 **不会** 自动带 `_openid`，所以**不要**选「仅创建者可读写」，否则小程序端读不到设备上传的数据
3. （可选，推荐）**索引管理** → 添加 `dedupId` 唯一索引、`createdAt` 降序索引（见上一节）
4. 若控制台提供**自定义安全规则**，可等价写成：
   ```json
   { "read": true, "write": false }
   ```
   > 上线前请收紧为 `{ "read": "doc.openid == auth.openid", "write": false }`，
   > 并让 `deviceUpload` 按 `devices.ownerOpenid` 回填 `openid`（§7.1 / §4.1）。

### 步骤 3：上传部署云函数 `deviceUpload`

1. 在开发者工具左侧文件树找到 `cloudfunctions/deviceUpload`
2. **右键该目录** → **上传并部署：云端安装依赖（不上传 node_modules）**
3. 等待提示「上传成功」（首次会自动安装 `wx-server-sdk`）
4. 部署完成后，在 云开发控制台 → **云函数** → 应能看到 `deviceUpload`

> 若你的环境需要 **HTTP 云函数 / HTTP 访问服务** 供 ESP32 直接 POST：
> 控制台 → 云函数 → `deviceUpload` → **触发方式/HTTP 访问服务** → 新增路径（如 `/deviceUpload`），
> 得到形如 `https://<环境ID>.service.tcloudcloud...` 的 HTTPS 地址。
> 具体入口文案以你的控制台为准；**M1 不依赖它也能验证**（用控制台「云端测试」即可）。

### 步骤 4（可选但强烈建议）：改掉占位密钥

编辑 `cloudfunctions/deviceUpload/index.js`：

```js
const SHARED_TOKEN = "REPLACE_ME";   // ← 改成你自己的随机长字符串（≥32 位）
```

改完 **重新上传部署**。设备/测试请求体里带同样的 `token`。
> M1 允许沿用 `REPLACE_ME` 以便先跑通（返回里会带 `insecure: true` 提醒），
> **上线必须替换，并按 §5.3 改用 HMAC-SHA256 验签 + 时间窗 + nonce 防重放**。

## 4. 如何验证 M1 跑通

### 4.1 第一步：手动插一条记录（不依赖设备）

云开发控制台 → 数据库 → `experiments` → **添加记录**（JSON 模式），粘贴：

```json
{
  "deviceId": "YD32S3-3C6108A1",
  "fabricName": "纯棉平纹40支",
  "operator": "",
  "softness": 0.62,
  "smoothness": 0.71,
  "roughness": 0.24,
  "rebound": 0.55,
  "composite": 72.4,
  "metricsNormalized": true,
  "weights": { "softness": 0.30, "smoothness": 0.25, "roughness": 0.20, "rebound": 0.25 },
  "curveRef": "",
  "dedupId": "MANUAL-TEST-0001",
  "source": "device",
  "startedAt": { "$date": "2026-09-06T10:21:03.000Z" },
  "createdAt": { "$date": "2026-09-06T10:21:40.000Z" }
}
```

> 控制台添加记录时，日期字段直接选「日期」类型并填时间即可（不同版本控制台 UI 略有差异）。
> 若 `createdAt` 填的是字符串，列表页也能正常显示（`utils/fmt.js` 做了多格式兼容），但**排序会不理想**，建议用日期类型。

### 4.2 第二步：验证列表页（首页）

1. 开发者工具点 **编译** → 默认进入 **实验记录** 页（首页已改为 `pages/list/list`）
2. 应看到一条卡片：**纯棉平纹40支 / 72.4分 / 2026-09-06 10:21 / 柔软62 顺滑71 细腻76 回弹55**
   - 「细腻」= `100 - roughness×100 = 100 - 24 = 76`（roughness 越小越细腻，展示时取反）
3. 多插几条记录（把 `createdAt` 设成不同时间）→ 下拉刷新 → 顺序应为 **倒序**（新的在上）
4. 插入 **21 条以上** → 上拉到底 → 底部出现「加载中…」，第二页被追加（每页 20 条）
5. 点任意一条 → 进入 **实验详情**：综合评分大数字、五边形雷达图（柔软/顺滑/细腻/回弹/综合）、四维数值条、布料名与时间

> 列表页底部/错误条会直接显示可读的失败原因，例如：
> 「集合 experiments 不存在：请在云开发控制台 → 数据库 → 新建集合 experiments」→ 回到步骤 2。

### 4.3 第三步：验证云函数 `deviceUpload`（幂等 + 密钥）

云开发控制台 → 云函数 → `deviceUpload` → **云端测试**，测试参数：

```json
{
  "token": "REPLACE_ME",
  "deviceId": "YD32S3-3C6108A1",
  "fabricName": "纯棉平纹40支",
  "operator": "",
  "softness": 0.62,
  "smoothness": 0.71,
  "roughness": 0.24,
  "rebound": 0.55,
  "composite": 72.4,
  "startedAt": 1756376463000,
  "dedupId": "YD32S3-3C6108A1-000042-0007"
}
```

预期返回：

```json
{ "ok": true, "id": "<新记录的 _id>", "dedup": false, "insecure": true }
```

**再点一次同样的测试**（关键：验证幂等）：

```json
{ "ok": true, "id": "<同一条 _id>", "dedup": true, "insecure": true }
```

→ `dedup: true` 且 `_id` 相同，说明不会重复入库。

**负数用例**：把 `token` 改成 `wrong` → 应返回 `{ "ok": false, "code": 4011, ... }`；
把 `softness` 删掉 → 应返回 `{ "ok": false, "code": 4003, "message": "缺少或非法字段：softness" }`。

### 4.4 第四步：回到列表页确认

回到小程序 → 下拉刷新 → 应看到刚由云函数写入的记录（`YD32S3-3C6108A1` / 72.4 分）。

## 5. 已知限制 / 需要确认的点（M1 有意取舍）

1. **列表为客户端直读数据库**：因此 `experiments` 的读权限在 M1 必须放开（见步骤 2）。
   方案 §7.1 的最终形态是「客户端只读本人 + 写禁止」；那需要先有设备绑定（`devices.ownerOpenid` → 回填 `openid`），属 M4。
2. **写入口只有云函数**：小程序端**不会**写库（`utils/cloud.js` 只提供读），符合方案「客户端一律不写库」。
3. **分页无 total**：读取次数考虑，M1 不调 `count()`，用「取满一页即认为还有下一页」判断；
   代价是记录数恰为 20 的整数倍时会多请求一次空页（表现为短暂「加载中」后提示「没有更多了」）。
4. **雷达图只有四维 + 综合**（五边形），未画背景刻度数值；曲线图（`curveRef`）留到 M2。
5. **`startedAt` 缺失时退化为入库时刻**，未实现 §5.6 的 `timeSource: "estimated"` 标记（M1 字段裁剪）。
6. **鉴权为共享密钥占位**，非 HMAC；`insecure: true` 是提醒信号。上线前必须替换 `SHARED_TOKEN` 并改 HMAC（§5.3）。
7. **`app.json` 的 `navigationBarTitleText` 已从「云开发 QuickStart」改为「织物触觉舒适度检测」**，
   如希望保留模板原字样，改回即可（列表/详情页各自在 `*.json` 里单独设了标题，不受影响）。
8. 页面样式为 M1 简约实现（卡片 + 数值条），**未做**筛选、搜索、曲线导出、评分区间过滤等（M2/M3）。
